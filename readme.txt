================================================================
  TB01 迅雷下载宝 · 重生计划
  基于 OpenWrt 25.12 的全能小型旁路由改造项目
================================================================


一、这是什么项目
----------------------------------------------------------------
TB01"迅雷下载宝"是迅雷早期推出的一款入门级下载设备。
受限于出厂系统封闭、生态停滞，加上板载闪存容量紧张，
这台设备在很多人手里早已沦为"吃灰神器"。

本项目的目标，就是让这台过时的下载宝重获新生：
通过刷入 OpenWrt 25.12 固件，将其改造为一台集
"旁路由代理 + 局域网文件分享 + PT 下载"于一体的
低功耗、低占用的全能小主机，让老硬件继续发光发热。


二、TB01 硬件参数
----------------------------------------------------------------
基本规格
- 处理器：MediaTek MT7621AT，双核四线程，880MHz
- 内存：256MB DDR3
- 板载闪存：16MB SPI NOR
- 内置存储：无（需扩展SD卡/外接 USB 存储设备）

接口
- 1 × USB 3.0 接口（对外供电 DC 5V / 1.5A，最大支持6T）
- 1 × 10/100/1000M 自适应千兆网口
- 1 × SD 卡插槽（官方最大支持 128GB）
- 1 × 恢复出厂设置按键
- 1 × 硬盘安全移除按键
- 1 × 橙 / 白双色 LED 指示灯

电源与外观
- 电源输入：DC 5V / 2A
- 尺寸：90 × 87 × 22mm，重量约 85g

原厂限制（本项目的改造动因）
- 原厂系统封闭，配套远程服务器早已停服，设备形同"废铁"；
- 原厂固件不支持将 SD 卡作为下载存储介质；
- 仅 16MB 板载闪存，留给系统与软件的空间捉襟见肘。

正是这些限制，催生了"基础包 + SD 卡"的分层改造思路（详见下文）。


三、核心目标
----------------------------------------------------------------
1. 系统翻新
   将设备刷入 OpenWrt 25.12，彻底摆脱封闭的出厂系统。

2. 功能重建
   - Xray 核心旁路由：透明代理，局域网设备免配置接入；
   - dnsmasq：轻量级 DNS / DHCP 服务，域名解析与管理；
   - Samba：局域网文件分享，手机、电视、电脑随时访问；
   - Transmission：经典 PT 下载客户端，支持 Web 远程管理。

3. 存储策略（基础包 + SD 卡）
   受限于板载闪存容量，采用分层安装方案：
   - 固件基础包仅负责挂载 SD 卡及必要的系统配置；
   - 其余所有 package（Xray、Transmission、Samba 等）
     一律安装到 SD 卡上；
   - 既绕开了闪存空间瓶颈，也便于整体备份与迁移。

4. 内存控制
   通过精简系统服务与合理的软件布局，使内存长期保持稳定：
   free 内存在 100M ~ 20M 之间浮动
   （视 Transmission 当前下载任务量而定），
   长时间运行不轻易 OOM，保证系统平稳可用。


四、功能特性
----------------------------------------------------------------
- Xray 核心旁路由
  以旁路由模式接入现有网络，无需改动主路由配置；
  透明代理，支持全局 / 分流等多种策略，开箱即用。

- dnsmasq
  提供 DNS 转发与地址解析管理，与旁路由协同工作，
  实现更灵活的网络解析与访问控制。

- Samba 局域网分享
  基于 SD 卡 / 外接存储建立共享目录，
  跨平台访问（Windows / macOS / Linux / Android / 电视盒子）。

- Transmission PT 下载
  经典 PT 客户端，支持种子与磁力链接；
  自带 Web 管理界面，可远程添加、管理下载任务；
  缓存大小与任务数量可根据内存余量灵活调整。

- SD 卡扩展
  固件基础包内置 SD 卡挂载与开机自挂载能力，
  为应用层 package 与下载数据提供充足空间。


五、技术方案
----------------------------------------------------------------
- 固件层：OpenWrt 25.12 基础包，保持精简，
  仅保留系统核心、网络基础组件与 SD 卡挂载能力。

- 应用层：所有功能 package 安装于 SD 卡，
  通过挂载 / overlay 方式运行，与固件解耦，
  升级固件不影响应用数据。

- 内存策略：
  1) 关闭非必要系统服务，精简开机自启项；
  2) Transmission 缓存与并发任务按内存余量动态调整；
  3) 通过内存监控观察运行状态，确保长期稳定。


六、内存表现
----------------------------------------------------------------
- 空闲待机：free 稳定在 100M 左右；
- 满载下载：Transmission 多任务高缓存时，
  free 回落至 20M 上下；
  transmission做种的数量几乎不太吃内存，同时下载大体积种子时，内存飙升明显，推荐同时下载4个，其他的队列等待。如30分钟没任何数据下载，该种子会自动暂停，进入等待队列，下载下一个。
- 内存余量随下载负载动态浮动，整体保持稳定可用。


七、适用场景
----------------------------------------------------------------
- 想低成本实现"旁路由代理 + 基础 NAS 分享"，
  却不想折腾主路由的用户；
- 手上正好闲置一台 TB01，希望让它物尽其用的玩家；
- 对低功耗、低占用、长稳运行有要求的轻量网络场景。


八、项目理念
----------------------------------------------------------------
让老设备重获新生，而不是被时代淘汰。

一台十年前的小盒子，在今天依然可以
安静地承担起代理、分享与下载的职责——
这正是本项目存在的意义。
